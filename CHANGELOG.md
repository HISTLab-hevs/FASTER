# Changelog

Notable changes are recorded here from 1.0.0 onward. Everything before it
happened in a private repository with no users to notify, so there is no earlier
released version for those changes to be described against; the git history is
that record.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning is [semantic](https://semver.org/). A run configuration written for
one minor version keeps working on the next; a change to what a stored run
means, such as the config schema, the contents of `metrics.json`, or the layout
of a results folder, is a breaking change and waits for a major release.
